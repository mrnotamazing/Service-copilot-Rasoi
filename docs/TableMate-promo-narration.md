# TableMate promo film: narration script

Calm and conversational. It adds meaning to the pictures rather than reading the screen. Voice speed about 0.92, with a soft music bed that dips under the voice. The picture and timings are in `src/pages/intro/scenes.tsx`.

| Scene | Narration |
| --- | --- |
| 1 · Open | This is TableMate. A calm partner for the busiest nights. |
| 2 · Pressure | Picture a busy Saturday. Everyone needs something, and all at once. |
| 3 · Slip | Then the kitchen runs late, and somehow it's the server who takes the blame. |
| 4 · Next three | TableMate lightens the load. It shows each server just three next steps, and why each one matters. |
| 5 · Safety | When it truly matters, like an allergy, it speaks up before the plate is made. |
| 6 · Fair delays | Afterwards, every delay is credited fairly, so no one carries blame that was never theirs. |
| 7 · Manager | Managers see where help is needed, not a ranking, and can match guests with the right server. |
| 8 · Practice | Between rushes, servers practise the hard moments in private, and grow at their own pace. |
| 9 · Everyone | In their own language, in whatever way works best for them. |
| 10 · Close | Quick. Correct. Together. … TableMate. The right service, at the right time. |
